# Estudos ENEM

Plataforma pessoal de preparação intensiva para o ENEM 2026, construída para uma janela
curta de estudo (~48 dias) e para um único aluno.

A lógica do produto é **diagnosticar → priorizar → estudar → praticar → corrigir → revisar**.

- [Etapa 1 — Pesquisa, estratégia e especificação](docs/ETAPA-1-ESPECIFICACAO.md)

## Procedência do conteúdo

Todo conteúdo do site é marcado em três níveis: `OFICIAL` (documentado pelo INEP/MEC),
`ANÁLISE` (julgamento pedagógico) e `AUTORAL` (criado para este site). Nenhuma questão
criada para o site é apresentada como questão oficial do ENEM.
